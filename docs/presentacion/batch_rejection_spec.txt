# ESPECIFICACIÓN TÉCNICA: BATCH REJECTION PRE-ADAM (GRADIENT GUARD) PARA TDV

## 1. OBJETIVO Y CONTEXTO
Implementar un filtro de rechazo de lotes anómalos (Batch Rejection) pre-Adam para evitar la inestabilidad en el entrenamiento de Total Deep Variation (TDV). 
El mecanismo previene que picos aislados en la norma del gradiente corruptan los momentos de primer y segundo orden de Adam (m_hat, v_hat), impidiendo que el optimizador alinee los conos espectrales de la Hessiana en el backward pass y construya el amplificador (sigma_max > 16.5).

---

## 2. REQUISITOS DE EFICIENCIA COMPUTACIONAL
- **Lugar de ejecución:** Inmediatamente después de `loss.backward()` y ANTES de `optimizer.step()`.
- **Costo:** O(1) estricto (menos de 0.5 ms en GPU). Debe calcular únicamente la norma L2 global del vector de gradiente acumulado sin recalcular gráficas ni ejecutar pasadas adicionales.
- **Acción:** Si la norma excede la cota, ejecutar `optimizer.zero_grad()` y OMITIR `optimizer.step()`.

---

## 3. FUNDAMENTACIÓN MATEMÁTICA Y COTAS TEÓRICAS

### A. Cota Dinámica (Saturación de Memoria Adaptativa de Adam)
Adam acumula el promedio móvil del cuadrado del gradiente con beta2 = 0.999. El horizonte de memoria efectiva es:
    N_eff = 1 / (1 - beta2) = 1000 iteraciones

Para evitar que un solo lote distorsione el denominador de Adam por 1000 iteraciones, el paso actual no puede superar la mediana/EMA reciente por un factor mayor a la desviación límite de la memoria:
    R_Adam = 1 / sqrt(1 - beta2) = sqrt(1000) ≈ 31.62

Formula Dinámica:
    Threshold_Adam = R_Adam * EMA(||g||_2)

### B. Cota Teórica de Descenso Suficiente (L-Smoothness)
Según el Lema de Descenso para optimización no convexa L-suave, para garantizar que la actualización no cause un incremento monótono de la pérdida, la norma máxima del gradiente está acotada por:
    G_max = (2 * Loss_0) / (eta * sqrt(S))

Donde:
- Loss_0 ≈ 250 (Pérdida inicial típica)
- eta = 4e-4 (Learning Rate)
- S = 10 (Pasos desenrollados de TDV)
Calculo:
    G_max ≈ 500 / (4e-4 * sqrt(10)) ≈ 3.95e5

### C. Cota Efectiva Combinada
    Threshold_eff = min( R_Adam * EMA(||g||_2), G_max )

## 4. ESTRUCTURA DE IMPLEMENTACIÓN (PyTorch O(1))

```python
import torch
import math

class GradientGuard:
    def __init__(self, beta_ema=0.99, max_ratio=31.62, fallback_cutoff=3.95e5):
        self.beta_ema = beta_ema
        self.max_ratio = max_ratio          # Derivado de 1 / sqrt(1 - beta2)
        self.fallback_cutoff = fallback_cutoff # Derivado del Lema de Descenso
        self.ema_norm = None
        self.rejected_count = 0
        self.total_count = 0

    @torch.no_grad()
    def check_and_step(self, model, optimizer):
        self.total_count += 1
        
        # 1. Recolectar parámetros con gradiente
        grads = [p.grad for p in model.parameters() if p.grad is not None]
        if not grads:
            return True

        # 2. Calcular norma L2 global en GPU (Costo O(1))
        device = grads[0].device
        total_norm_sq = torch.sum(torch.stack([torch.sum(g ** 2) for g in grads]))
        grad_norm = torch.sqrt(total_norm_sq).item()

        # 3. Control de Infs / NaNs
        if math.isnan(grad_norm) or math.isinf(grad_norm):
            optimizer.zero_grad()
            self.rejected_count += 1
            return False

        # Inicialización de EMA
        if self.ema_norm is None:
            self.ema_norm = grad_norm

        # 4. Evaluación de Cota
        threshold_adam = self.ema_norm * self.max_ratio
        effective_threshold = min(threshold_adam, self.fallback_cutoff)

        if grad_norm > effective_threshold:
            # RECHAZO DE BATCH: Se limpian gradientes y no se actualizan pesos ni Adam
            optimizer.zero_grad()
            self.rejected_count += 1
            return False
        else:
            # ACEPTACIÓN: Se actualiza la EMA y se procede con el paso de optimización
            self.ema_norm = self.beta_ema * self.ema_norm + (1 - self.beta_ema) * grad_norm
            optimizer.step()
            return True
```

## 5. EXPERIMENTACIÓN Y PARÁMETROS A ITERAR

Instrucciones para la IA ejecutora al probar en `train.py` / `train.txt`:

1. **Sensibilidad de `max_ratio`:**
   - Probar valores en la grilla: `[10.0, 20.0, 31.62, 50.0]`.
   - Evaluar la tasa de rechazo (% de lotes saltados). Debe mantenerse por debajo del 1% - 2% en entrenamientos sanos.

2. **Inercia de `beta_ema`:**
   - Probar `[0.95, 0.99, 0.999]`. Un `beta_ema = 0.99` ofrece el mejor balance entre adaptación a la curva de aprendizaje y filtro contra picos aislados.

3. **Métricas de Telemetría a Registrar:**
   - Registrar en las trazas `.npy` / TensorBoard:
     * `grad_norm_raw`: Norma del gradiente antes del guard.
     * `ema_norm`: Evolución del promedio móvil.
     * `rejected_flag`: Booleano indicando si la iteración fue saltada.
     * `rejection_rate`: Porcentaje acumulado de rechazos.

4. **Verificación de éxito:**
   - El entrenamiento no debe congelarse (la loss debe descender continuamente).
   - Los saltos repentinos de norma (||g|| > 10^4) deben ser interceptados antes de alterar `T` o la `VNet`.
   - `T` debe co-evolucionar suavemente sin colapsar a 0.0 ni requerir clamps artificiales (`t_min`).
